# PDF 原版阅读：阶段 1

只实现原 PDF 阅读，不包含翻译、OCR 或版面识别模型。PDF.js 保持 4.10.38，
没有新增运行依赖；直接使用现有 PDF.js 组件，不复制 reader 项目的实现。

## 导入和兼容

- 选择 PDF 后，在导入弹窗选择原版（默认）或重排；一次多选 PDF 使用同一选择。
- 阅读方式放进来源键，两种方式保存为独立书籍；不覆盖旧书和另一种方式。
- 两种方式都把原 PDF 存到原有 IndexedDB `readtaylor/files`，按 SHA-256 标识。
- 原版元数据保留页数及每个物理页的 `pagesWithText`。无文字不等于一定是扫描页，
  也可能是空白页或文字已转曲。本阶段不做 OCR，不判断内容语义。
- 旧 PDF 保留原来的阅读器和数据，显示重新导入提示；旧 EPUB 不迁移。
- 原版位置保存在 `readtaylor.pdf-positions.v1`，与重排位置完全分开，
  使用文件哈希、1 起始物理页、PDF 用户坐标、缩放方式和旋转角度。

## 页面接口

`PdfReaderView.onPageAccess` 提供 `PdfPageAccess`，卸载时传 `null`。
`getPageGeometry(pageNumber)` 返回页面容器、当前 CSS 尺寸、PDF 边界、旋转角度，
以及 `pdfToClient`、`clientToPdf`、`pdfRectToClient`；`goToPage` 可带 PDF 坐标。
缩放或旋转后重新获取 geometry；PDF 用户空间与浏览器客户区坐标不可混用。
本阶段没有绘制文字块或请求翻译。

## 验证步骤

生成原创测试样本（默认输出也可指定临时目录）：

```powershell
node scripts/pdf-reader-fixtures.mjs "$env:TEMP/readtaylor-pdf-stage1"
node --test scripts/pdf-position.test.mjs
node --test electron/*.test.cjs
node node_modules/typescript/bin/tsc --noEmit
npm run build
```

1. 导入 `two-column.pdf`，默认原版；核对两栏、矢量图、文本选择。
2. 导入 `scanned.pdf`：各页可读，出现无文字层提示，不要求 OCR 搜索命中。
3. 导入 `mixed.pdf`：第 2、4 页有提示，第 1、3 页没有提示。
4. 导入 `long-72-pages.pdf`：跳到第 60 页，开发者工具检查 `.pdfViewer canvas`，
   只保留可见区域附近的页面，而不是 72 张 Canvas。
5. 搜索 `Left 67.30:`，应只有一个结果并跳到第 67 页；上／下一个结果可循环。
6. 打开目录，点击 `Final physical page` 到最后一页；页顶链接也可到最后一页。
7. 分别试适应宽度、适应页面和 150%；文字可双击选择，文本层与 Canvas 对齐。
8. 在文档中部滚动到半页，旋转 90°；返回书架、刷新，再打开，恢复页内位置、
   缩放和旋转。物理页不应写入旧的 `lastPage`。
9. 夜间模式周围界面变暗，原 PDF 保持白底和原图颜色；窄屏工具栏换行。
10. 同一 PDF 再以重排方式导入，两个条目独立可读；原文件仍保存在本机。
11. 打开既有 EPUB：图片、目录、翻页、重开位置应正常；旧 PDF 不被转换或清除。
12. 补充真实双栏论文、公式、复杂图表和 60 页以上扫描长文；合成样本不代表所有论文。

## 已知局限

- 加密 PDF 暂无密码输入界面，导入或打开时明确报错。
- 扫描页只能看，不能搜索图片里的字；损坏的文本编码也可能导致搜索不准确。
- 导入要计算整份文件哈希并逐页检查文字层，大文件导入仍需要时间和内存；
  阅读阶段按需渲染，不预先把整篇转成图片。
- 每张 Canvas 最多 8M 像素，极高缩放下可能降低清晰度以控制内存。
- PDF.js 位置坐标取整，因此恢复允许约 1–2 CSS 像素的误差。
- 旧 PDF 的原文件无法从重排文字恢复；需要重新导入，不自动迁移旧笔记坐标。
- 浏览器清理网站数据会删除本机资料；本阶段没有云同步、备份、打印和编辑功能。
- 桌面与网页共用阅读组件；原生安装包、不同显卡及异常 PDF 仍需交叉验收。

## 本轮验证记录（2026-10-17）

- 类型检查、生产构建通过；4 项位置／旧数据兼容测试和 5 项既有桌面测试通过。
- 浏览器实际导入 BERT（16 页）、Attention（15 页）及原创合成 PDF；
  BERT 的双栏和跨栏图保持原样，扫描／混合页提示正确。
- 72 页样本跳到第 60 页后，只存在附近页面的 Canvas（观测 1–3 张）；
  搜索 `Left 67.30:` 命中一次，跳至第 67 页。大纲、页内链接能跳至第 72 页。
- 150% 缩放时 Canvas 与文本层边界一致，可双击选中文字。
  90° 旋转及页内滚动后，返回、刷新、重开恢复；观测偏差不足 1 CSS 像素。
- 原文件 SHA-256 与页面绑定的源文件哈希一致；新导入的重排 PDF 与原版条目并存。
- 夜间模式保持 PDF 原色；390×844 视口下工具栏不越出页面。
- 既有 EPUB 的图片、目录及翻页通过浏览器回归；旧 PDF 数据保持不变由单元测试覆盖，
  尚需用户自己的旧 PDF 书目实测。
- 未实测原生 Electron 安装包，也未用真实 60 页以上扫描长文做性能基准。
  合成样本与本机交互结果不代表所有 PDF 或设备的性能保证。
- 本地 PDF.js 字体、CMap 和图标资源约 2 MB，按需读取；新增阅读器代码独立懒加载，
  不增加模型、OCR 或新的运行依赖。
